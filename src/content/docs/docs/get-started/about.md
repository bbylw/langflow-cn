Langflow 是一个开源、基于 Python 的 AI 应用构建框架。它用来搭建智能体（Agent）并支持模型上下文协议（MCP），且不强制你绑定某一个大语言模型或向量数据库。

## 它如何工作

你通过 **Flow（流程）** 来表达应用逻辑：一个 Flow 由若干 **Component（组件）** 连接而成，每个组件是一个配置好的步骤。

- 在**可视化编辑器**里拖拽、连线即可组装并查看行为。
- 在 **Playground** 里无需搭完整应用栈就能实时交互。
- 单个组件也能独立运行，以核对它的输入输出。

做好之后，Flow 既可以当原型，也可以通过 API 嵌入到你的代码里、作为依赖被引用，或部署到一台可公网访问的服务器上。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 构建 AI 应用 | 对话机器人、文档分析、内容生成、智能体应用都适用 |
| 现成起点 | 内置大量模板，可直接用也可改 |
| 通用积木 | 输入、输出、数据存储等通用组件，加上智能体、语言模型、嵌入模型等专用组件 |
| 参数控制 | 组件参数可固定，也可随运行变化 |
| 运行时覆盖 | 用 tweaks 在运行时临时改配置，不动已保存的 Flow |
| 智能体工具 | 把组件或整条流程作为工具挂到 Agent 上 |
| MCP 双向 | 既能作为 MCP 服务器暴露能力，也能作为客户端接入外部 MCP |
| 可扩展 | 支持自定义组件，自己写或用别人分享的 |
